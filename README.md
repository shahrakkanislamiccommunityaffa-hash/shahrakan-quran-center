# تعليم القرآن - تسجيل الحضور (مركز شهركان الإسلامي)

موقع فيه:
- تسجيل دخول بيوزر وباسورد (أدمن واحد بس، بدون حسابات ثانية).
- **تسجيل حضور المعلمين**: اسم المعلم + التاريخ.
- **تسجيل حضور الطلاب**: اختيار المرحلة (الصفوف / الملفات-الحلقات) ← اختيار الصف أو الملف ← قائمة الطلاب مع تسجيل حاضر/غائب لكل واحد بتاريخ معيّن، وبيانات كل طالب (المستوى، رقم ولي الأمر، ملاحظات) محفوظة بملفه الدائم.

كل البيانات تتخزن بقاعدة بيانات واحدة، فأي جهاز يفتح الموقع يشوف آخر تحديث فوراً.

---

## ١) التشغيل محلياً (اختياري، للتجربة)

1. ثبّت [Node.js](https://nodejs.org) نسخة ١٨ أو أحدث.
2. داخل مجلد المشروع:
   ```
   npm install
   cp .env.example .env
   ```
3. عبّي ملف `.env`.
4. شغّل: `npm start`
5. افتح `http://localhost:3000`

---

## ٢) قاعدة البيانات (MongoDB Atlas)

تقدر تستخدم **نفس حساب MongoDB Atlas** اللي سويته لموقع الفعاليات بالضبط — بس لازم تسوي قاعدة بيانات (database) منفصلة لهذا الموقع حتى ما تختلط البيانات:

1. من نفس الـ Cluster اللي عندك بـ Atlas، اضغط **Connect → Drivers** وانسخ رابط الاتصال.
2. غيّر اسم قاعدة البيانات بنهاية الرابط من اللي كان لموقع الفعاليات (مثلاً `shahrakkanislamic-events`) إلى اسم جديد مثل `quran_attendance`.
3. هذا الرابط الجديد هو `MONGODB_URI` الخاص بهذا الموقع — حطه بملف `.env` أو بمتغيرات البيئة بـ Render.

*(ما تحتاج تعيد خطوات إنشاء مستخدم قاعدة البيانات أو فتح الوصول — نفسها من قبل تكفي، لأنها على مستوى الحساب/الـ Cluster مو على مستوى القاعدة.)*

---

## ٣) نشر الموقع مجاناً (Render.com)

1. ارفع مجلد المشروع كـ **repository جديد منفصل** على GitHub (غير ريبو موقع الفعاليات).
2. من [render.com](https://render.com): **New → Web Service** → اربطه بالـ repository الجديد.
3. الإعدادات: Build Command: `npm install` — Start Command: `npm start` — Instance: Free.
4. Environment Variables: `MONGODB_URI` (من الخطوة ٢)، `JWT_SECRET` (نص عشوائي طويل **مختلف** عن موقع الفعاليات)، `ADMIN_USERNAME`، `ADMIN_PASSWORD`.
5. **Create Web Service** → بتحصل رابط رسمي منفصل تماماً عن موقع الفعاليات.

---

## ٤) أول استخدام

1. سجّل دخول بـ `ADMIN_USERNAME`/`ADMIN_PASSWORD`.
2. من صفحة "حضور الطلاب": اختر المرحلة (صفوف/ملفات) → أضف صف أو ملف جديد (بالاسم واسم الأستاذ) → افتحه → أضف الطلاب → سجّل الحضور اليومي.
3. من صفحة "حضور المعلمين": سجّل اسم المعلم والتاريخ مباشرة.

---

## ملاحظات أمان

- غيّر `ADMIN_PASSWORD` لشي قوي، وما تشارك ملف `.env` مع أحد.
- كلمة المرور تُخزن مشفّرة (bcrypt).
